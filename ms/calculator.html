Alat 07

Penghawa pam haba biogas (BHP) → penyejukan tanpa grid

Pejabat, makmal dan perumahan pekerja; kecuali penyejukan proses.
Kelas dipacu enjin: 0.95–1.15 bergantung ambien dan beban separa.
Biometana 97% ialah bahan api standard; biogas mentah perlu penurunan kuasa dan selang servis lebih pendek.
Indikatif RM 2,500/kW penyejukan, pemasangan tidak termasuk.
Biogas sendiri ≈ RM 0.60/Nm³; biometana botol RM 1.00–1.40.
Grid 0.35–0.50; dijana diesel 0.90–1.60 setelah logistik dan masa henti dikira.
VRF/chiller 2.8–3.5 dalam keadaan tropika.
25% input bahan api tersedia sebagai air 60–90 °C dalam mod penyejukan. Set 0 jika tidak digunakan.
Servis enjin, minyak dan penapis: 3–4% lazim.

LHV metana 9.94 kWh/Nm³. Input bahan api = penyejukan ÷ COP; haba = 25% input dalam mod penyejukan; air panas ΔT 50 K. Sistem pembanding membeli kWh dari grid atau genset diesel dan membuat penyejukan pada COP elektrik dinyatakan. CO₂ pada 0.60 t/MWh. Indikatif sahaja.

Kaedah & pemalar. LHV metana 35.8 MJ/Nm³ = 9.94 kWh/Nm³. Tenaga biogas = aliran × pecahan CH₄ × 9.94. Output elektrik = tenaga bahan api × kecekapan. Haba boleh pulih = tenaga bahan api × pecahan haba. Semua keputusan indikatif; jaminan hanya berdasarkan data tapak yang diukur.
