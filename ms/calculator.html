Alat 05

Ekonomi projek

Pakej enjin FOB ≈ USD 580–630/kW (600–800 kW); loji lengkap biasanya USD 1,800–2,600/kW.
Diesel pedalaman Sabah: RM 0.55–0.75. Import grid RM 0.40–0.50. Indonesia USD 0.07–0.10.
Hanya kWh digunakan sendiri membawa nilai penuh.

Kaedah & pemalar. LHV metana 35.8 MJ/Nm³ = 9.94 kWh/Nm³. Tenaga biogas = aliran × pecahan CH₄ × 9.94. Output elektrik = tenaga bahan api × kecekapan. Haba boleh pulih = tenaga bahan api × pecahan haba. Semua keputusan indikatif; jaminan hanya berdasarkan data tapak yang diukur.

Mengapa kami terbitkan formula. Kebanyakan kalkulator pembekal menyembunyikan andaian. Projek biogas ditentukan oleh kualiti gas dan jam operasi, bukan angka yang digilap.
