Kaedah & pemalar. LHV metana 35.8 MJ/Nm³ = 9.94 kWh/Nm³. Tenaga biogas = aliran × pecahan CH₄ × 9.94. Output elektrik = tenaga bahan api × kecekapan. Haba boleh pulih = tenaga bahan api × pecahan haba. Semua keputusan indikatif; jaminan hanya berdasarkan data tapak yang diukur. Mengapa kami terbitkan formula.
